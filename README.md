# Cortex Site

Marketing website for Cortex — the intelligence layer for teams building critical systems. Built with React 19 + Vite + TypeScript + Tailwind CSS.

**Key features:**
- React 19 SPA with Vite 7
- shadcn-ui component library (53 components)
- Tailwind CSS 4 with Silverline Systems design
- Express server with AI Core grounded chat endpoint
- TypeScript throughout

**Available scripts:**
- `dev` - Start Vite dev server
- `build` - Build client and server
- `start` - Run production server
- `check` - Type-check with tsc
- `format` - Format with Prettier
